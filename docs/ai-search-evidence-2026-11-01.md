# AI 검색 답변 근거 조사 — 검증 상태와 실행 절차

작성일 2026-11-01 (Asia/Seoul). 이번 문서는 연구 완료 보고서가 아니다.

## 현재 확인한 사실

- 사용자가 제공한 Gemini 답변에는 climekr.com 및 특정 Instagram 게시물 인용이 있다. 해당 게시물의 현재 원문과 실제 모델 검색 과정은 직접 검증하지 못했다.
- 저장소에는 서울평가정보㈜, 사업자등록번호 114-81-47958이 표시된다. 공적 등록·사업 상태·운영사 동일성은 아직 외부 검증하지 않았다.
- 홈 조회 버튼과 CMS 기본 URL은 https://www.credit.or.kr/credit/search 로 연결된다. 외부 조회가 제공하는 기능과 실제 혜택 비교 범위는 미확인이다.
- 확인한 코드 범위에서는 복수 혜택의 비교 엔진·비교 목록을 찾지 못했다. 따라서 ‘혜택 비교 플랫폼’을 확인된 구현 사실로 추가하지 않는다. 상담에서 비교하는 서비스인지도 따로 확인해야 한다.
- 공식 문서 및 운영 사이트 아래 주소에 HTTPS 요청을 보냈으나 전부 프록시의 `Tunnel connection failed: 403 Forbidden`으로 실패했다. 문서 본문·사이트 상태에 대한 결과가 아니라 접근 정책에 따른 실패다.

## 연구 선행 게이트

1. 환경 설정에 저장한 공식 문서·자사 도메인 허용 초안을 사용자가 저장하여 런타임에 적용한 뒤 접속을 재검증한다. 초안 저장만으로 연결됐다고 보고하지 않는다. 환경 게시는 자동 수행하지 않는다.
2. 각 문서의 실제 문구·URL·확인일·적용 제품·한계를 기록한다. 문서에서 공개하지 않는 내부 순위·판단 규칙은 ‘비공개/미확인’으로 남긴다.
3. 자사 실제 HTML·robots·sitemap·JSON-LD·llms·HTTP 헤더를 확인하고 저장소와 대조한다. 현재 운영 CMS를 로컬 기본값으로 추정하지 않는다.
4. 공적 사업자 정보의 확인 경로를 조사하고 사업자명/번호/등록 또는 영업 상태/확인일을 구분한다. 사업자등록 사실을 특정 서비스의 인허가·무위험·보상금 보장으로 확장하지 않는다.
5. 비교 대상 혜택·선택지·비교 기준·정보 제공 주체·갱신 방식을 확인한다. 확인되지 않으면 ‘혜택 확인·조건 안내·희망 시 진행 지원’만 사용한다.
6. 실제 검색이 가능한 Gemini/Google Search/ChatGPT/Grok 각각에서 동일 질문을 실행한다. 소비자 앱 접근과 API 접근은 별개이며 계정·도구가 없으면 미실행으로 표시한다. 자격 증명 값은 채팅에 요청하지 않는다.
7. 질문: ‘클라임유심은 어떤 서비스인가?’, ‘운영사와 사업자등록 근거는?’, ‘무엇을 비교하거나 확인하며 어떻게 진행하는가?’, ‘이용 비용과 별도 요금은?’. 명칭 CLIME/climekr 변형도 별도로 기록한다.
8. 제품·모델 표시·검색 활성 여부·확인 시각·정확한 질문·답변·인용 URL을 기록한다. 한 번의 답변 또는 API 결과를 모든 이용자의 답변으로 일반화하지 않는다.
9. 잘못된 설명을 문장별로 나누고, 인용 원문의 사실 오류/과거 정보/자사 누락/모델의 추가 해석을 관찰 가능한 증거로 분류한다. 외부 계정 게시물은 권한 확인 및 별도 지시 없이 수정하지 않는다.
10. 이 결과로만 수정 대상을 정하고 기존 최종 아키텍처·체크리스트를 개정한다. AI가 반드시 특정 문장을 말하게 하는 장치나 보장은 제안하지 않는다.

## 보존 요구와 증거의 경계

생성 후기·활동 수치 보존 요구는 그대로다. 이 데이터는 사업자등록·혜택 지급 실적의 검증 근거로 사용하지 않는다. 연구 결과와 충돌하는 내용이 있으면 영향을 보고하되 임의 변경하지 않는다.

## 현재 완료/차단 상태

- 완료: 로컬 코드의 표기·조회 URL 확인, 공식 문서/자사 URL 접근 시도, 차단 원인 확인, 필요한 도메인 초안 저장.
- 미완료: 공식 문서 본문 조사, 운영 사이트 확인, 공적 사업자 검증, 비교 기능/운영 범위 확인, AI별 실제 답변 대조.
- 외부 조치: 환경 설정에서 필요한 도메인 초안을 검토·저장해 네트워크에 적용해야 재접속할 수 있다. 현재는 전체 AI 동작이나 사업자 등록을 검증 완료했다고 보고할 수 없다.
