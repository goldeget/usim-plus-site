# 개통 전 조건 확인 흐름

## 의도

처음 방문한 사람이 먼저 참여 조건과 통신사 요금을 확인하고, 참여하기로 결정한 다음 개통과 사진 제출을 진행한다는 순서를 바로 이해하게 한다. 개통 현황 사진은 개통 후 증빙이므로 화면에서 개통 전 확인과 개통 후 신청을 분리한다.

## 접근 방식

1. 버튼 글자만 바꾼다. 수정 범위는 작지만 버튼을 눌렀을 때 사진 제출 폼이 열려 혼란이 남는다.
2. 첫 버튼은 참여 조건 안내를 열고, 안내의 다음 단계에서 개통 후 사진 신청으로 이어지게 한다. 화면이 설명하는 실제 절차와 버튼 동작이 일치하므로 이 방식을 선택한다.
3. 사진 없이 신청 가능 여부를 판정하는 별도 사전 심사 기능을 만든다. 현재 확인할 정보와 판정 기준이 정의되어 있지 않아 정확한 사전 판정을 약속할 수 없으므로 범위에서 제외한다.

## 선택한 설계

- 첫 버튼은 `참여 조건 먼저 확인하기`로 표시하고 조건 안내를 연다.
- 짧은 순서는 `개통 전 조건 확인 → 조건에 맞으면 개통 후 사진 제출 → 유지 조건 확인 후 지급`으로 안내한다.
- 상세 안내의 사진 신청 동작과 접수 폼은 이미 개통한 이용자에게만 권한다. 개통 현황 사진 제출 자체는 계속 실제 개통의 증빙으로 사용한다.
- 운영자가 수정하는 기본 문구, 검색 설명, AI 안내 문서도 같은 순서를 사용한다.
- 지급액, 유지 조건, 개인정보 처리, 통신사의 개통 판정 권한은 바꾸지 않는다.

## 완료 기준

- 첫 화면의 주요 버튼이 개통 전에 조건을 확인하도록 안내를 연다.
- 안내에서 조건을 확인한 뒤 개통하고, 개통 후에 사진을 보내는 순서를 이해할 수 있다.
- 사진 접수 폼은 개통 후 신청임을 분명히 알린다.
- API와 관리자 기본 문구 및 검색·AI 안내가 같은 순서를 설명한다.
- 기존 접수, 조회, 반응형 표시가 유지되고 전체 테스트와 배포 후 공개 화면 확인이 끝난다.
