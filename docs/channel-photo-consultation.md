# 상담창 사진 접수로 전환

2026-10-25 KST. 신규 접수는 LINE·텔레그램·채널톡의 운영자 대화창으로 연결한다. 홈페이지에서는 신규 파일 업로드와 접수번호 발급을 종료한다.

- 첫 화면 버튼은 상담 채널 선택으로 연결한다. 조회 사진과 결과 안내는 같은 대화에서 이어진다.
- 운영자는 `/admin/content.html` 첫 항목에서 사진 전송과 답장이 가능한 HTTPS 1:1 상담 주소를 등록한다. 공지 채널이나 구독 전용 주소를 사용하면 안 된다.
- 빈 상담 주소는 비활성으로 표시하며 이메일 문의를 제공한다. 실제 주소를 지어내거나 버튼 클릭만으로 신청 완료라고 안내하지 않는다.
- 기존 CMS 문구는 schemaVersion 3의 상담 방식으로 전환한다. 유효한 기존 상담 주소는 유지하고 예전 편집 화면의 저장은 새로고침 안내와 함께 거절한다.
- 새 접수 엔드포인트는 410을 반환하며 요청 사진을 읽거나 저장하지 않는다. 따라서 이전 홈페이지 탭으로 신규 사진을 접수할 수도 없다.
- 기존 신청의 접수번호·조회 코드 조회, 운영자 사진 검토, 비공개 R2 보관과 기존 만료 정책은 유지한다.
- 메신저 사진·대화·IP는 홈페이지의 기존 접수 목록에 자동으로 들어오지 않는다. 각 상담 서비스에서 직접 확인한다. 운영자 화면에도 이 범위를 표시한다.
- 새 상담 서비스의 사진 보관·삭제는 기존 홈페이지 자동 삭제와 연동되지 않는다. 운영자는 대화창에서 사진 전송 전 개인정보 이용·보관 안내를 제공하고 운영 정책에 따라 관리해야 한다.

## 배포 전 필요한 정보

운영자가 상담 주소를 어드민에서 직접 등록하기로 했으므로 주소가 비어 있어도 변경본을 배포한다. 등록 전에는 해당 채널을 ‘연결 준비 중’으로 표시하고 help@climekr.com 이메일 문의를 제공한다. 저장한 채널부터 홈페이지에 반영된다. 실제 메신저 사진 수신과 답장은 주소 등록 후 확인해야 한다.

## 검증

Node 테스트로 신규 접수 거절, 기존 상태 조회·운영자 보안·보관 정책, CMS 주소 보존·안전한 URL 검증·구버전 편집기 거절을 확인한다.
브라우저에서는 로컬 화면과 시험용 CMS 응답을 사용해 320px·390px·1440px에서 CTA 이동·초점, 미등록 안내, 주소 변경 반영, 실제 href와 새 창 연결, 기존 #apply/#statusLookupDetails 링크, 가로 넘침·스크립트 오류를 확인한다. 시험 주소는 실제 CMS나 운영 홈페이지에 등록하지 않는다. 외부 메신저의 실제 사진 수신과 답장은 실제 운영자 주소가 제공된 뒤 별도로 확인해야 한다.
