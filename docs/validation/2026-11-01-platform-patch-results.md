## 미검증·외부 한계

- Google/Gemini/xAI 일부 공식 문서는 읽었지만, 실제 소비자용 Gemini·Grok·ChatGPT 답변을 실행·대조하지 못했다. OpenAI 일부 문서와 운영 사이트는 현재 환경의 접근에서403을 반환했다. [조사 기록](../ai-search-evidence-2026-11-01.md) 참조.
- 사업자명·등록번호는 제공된 운영 정보로 표시한다. 공적 사업자등록·영업 상태를 독립적으로 조회 완료한 배지는 만들지 않았다.
- 여러 유심 상품을 비교하는 엔진·공식 제휴를 새로 구현하거나 확인됐다고 광고하지 않았다. 확인 가능한 ‘혜택 확인·조건 안내·희망 시 지원’ 범위를 사용한다.
- Firefox/WebKit 실행 파일은 환경에 없어 해당 엔진의 실브라우저 검증을 통과로 보고하지 않는다. 실제 모바일 OS 키보드·운영 데이터로 채운 관리자 업무도 미검증이다.
- 외부 AI의 특정 분류·문구를 강제로 막거나 앞으로 모든 입력에서 결함0임을 보장하지 않는다.

## 실행 시 판단

- 기존 격리 클라우드 체크아웃과 별도 브랜치를 사용했다. 추가 worktree를 만들지 않아 복원 경로를 유지했다.
- 이전 계획의 no-push 제한은 사용자의 후속 GitHub 보존 지시로 작업 브랜치에 한해 변경했다. 운영 배포 경계는 유지했다.
- 실제 비교 기능·공적 사업자 확인·AI 앱 실행 권한은 추정으로 채우지 않았다. 그 때문에 해당 기능/효과를 검증 완료로 표현하지 않는다.
- 공통 모듈과 페이지 통합을 묶어 순차 구현했고, 읽기 전용 연구와 화면 검사는 병행했다. 리뷰·원본 보존을 유지하면서 파일 충돌을 방지했다.
- 새 CTA 요청에 따라 재현된 고정 요소를 제거했다. 떠 있는 상담 버튼은 없어졌지만 기본 조회·상담 경로와 상세 정보는 유지된다.
