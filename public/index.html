사진 보관 안내
사진은 운영자 검토 후 30일, 미검토 상태에서는 접수 후 30일 동안 비공개 보관한 뒤 자동 삭제 처리됩니다. 사진 보관은 Cloudflare R2를 사용하며, 접수 상태 관리정보는 접수 또는 검토 결정 후 60일이 지나면 매일 정리 작업에서 삭제하며 실제 삭제 시점은 예약 작업 일정에 따라 달라질 수 있습니다.
개인정보 수집·이용 안내 자세히 보기
  • 수집 항목: 제출한 개통 현황 사진, 자동 생성 접수번호, 접수·검토 시각과 상태, 조회 토큰의 해시. 이름·전화번호·신분증·인증번호·비밀번호는 입력받지 않습니다.
  • 이용 목적: 제출 사진 접수, 운영자 사전 검토, 신청 상태 확인 및 처리 이력 관리.
  • 사진 보유 기간: 검토 결정 후 30일. 검토하지 않은 신청 사진은 접수 후 30일 보관합니다. 자동 삭제는 Cloudflare 저장소의 처리 일정에 따라 지연될 수 있습니다.
  • 접수 상태 관리정보 보유 기간: 사진의 30일 기본 보관 기간이 끝난 뒤에도 접수 또는 검토 결정 후 60일 경과 시점까지 상태 정보를 보관합니다. D1 관리정보는 60일이 경과하면 매일 자동 삭제 작업에서 정리하며, 실제 삭제 시점은 예약 작업 일정에 따라 달라질 수 있습니다. 삭제 후에는 접수 상태를 조회할 수 없습니다.
  • 보관 방법: 사진은 공개 주소가 없는 비공개 Cloudflare R2 저장소에 보관하고, 접수·검토 관리정보는 Cloudflare D1에 저장합니다. 사진 원본은 관리자 인증 화면을 통해서만 확인합니다.

자주 묻는 질문

사진을 첨부하면 누가 확인하나요?

접수 사진은 관리자 인증을 통과한 운영자가 사전심사합니다. 사진은 비공개 저장소에 보관하고 검토 결과 후 30일, 미검토 상태에서는 접수 후 30일 뒤 삭제 처리합니다.

사진에는 어떤 내용을 보여야 하나요?

현재 개통 현황과 심사에 필요한 항목이 식별되도록 첨부해 주세요. 주민등록번호 전체, 인증번호, 비밀번호 등 심사와 무관한 민감정보는 가려 주세요. 실제 제출 범위는 운영자의 개인정보 처리 안내를 확인하세요.

지급 금액과 신청 가능 개수는 어떻게 되나요?

3일 이상 유지 확인 시 개당 5만원을 지급합니다. 15일 유지 확인 시 개당 5만원, 30일 유지 확인 시 개당 7만원을 추가로 지급합니다. 한 사람 최대 3개까지 가능하고 실제 신청 가능 개수는 사람마다 다를 수 있습니다. 모든 조건을 충족하면 최대 51만원입니다. 3일 이상 유지 확인이 되지 않은 개통 건은 첫 5만원이 지급되지 않습니다.

30일이 지나면 어떻게 하나요?

30일 유지 확인 후 원하시면 자유롭게 해지하거나 추가 연장할 수 있습니다.

왜 참여자를 모집하나요?

통신사 개통 실적 향상을 위해 참여자를 모집합니다.

운영자 사전심사만 통과하면 개통이 확정되나요?

사전심사는 상담 진행 가능 여부를 확인하는 단계입니다. 실제 개통 가능 여부와 최종 가입은 통신사 공식 절차에서 확인됩니다.
